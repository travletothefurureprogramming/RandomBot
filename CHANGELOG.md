# [1.0.0] - 2026-09-25

### Added

- Initial release of RandomBot.
- Slack Bolt JS integration running on Socket Mode.
- Core commands: add, pick, list, clear and help
- Local JSON file persistence for saving the member list across app restarts
- Basic configuration setup with `.env` file for Slack tokens.
